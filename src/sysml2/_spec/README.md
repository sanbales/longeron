# Vendored OMG SysML v2 metamodel

`SysML.ecore` is the machine-readable abstract syntax (Ecore/EMF) from the
[SysML-v2-Pilot-Implementation](https://github.com/Systems-Modeling/SysML-v2-Pilot-Implementation)
(`org.omg.sysml/model/SysML.ecore`, nsURI 20250201). It is self-contained:
all KerML and SysML metaclasses (175 EClasses) in one EPackage.
Used by `sysml2.ecore` (optional, requires pyecore).
